# SHAREBAZAAR — COMPLETE DEMO VIDEO SCRIPT

**Target Duration:** 3–5 minutes
**Style:** Confident, polished, technical but easy to follow

---

# 1. DEMO OVERVIEW & STRATEGY — 30-SECOND OPENING

### Opening Visual

Start on the ShareBazaar login/auth screen.

Keep the UI clean and dark.

Then quickly transition to the Home dashboard showing multiple stocks with different attention levels.

### Core Narrative

Traditional watchlists are **passive**. They show prices, percentages, and volumes, but leave the investor to figure out what matters.

ShareBazaar changes that model.

Instead of simply asking:

**“What is the stock price?”**

ShareBazaar asks:

**“What changed since I last checked, how significant is that change, and what is driving it?”**

The key differentiator is the combination of:

**Last-seen baseline → meaningful change detection → 7-factor impact score → AI explanation.**

### 30-Second Opening Narration

> “Traditional stock watchlists give investors more numbers, but not necessarily more insight. A stock can move two percent, but without knowing where it started, how it performed against the market, or what caused the move, that number has very little context.
>
> ShareBazaar turns the traditional watchlist into an intelligent market dashboard. It remembers the price of every stock when the user last checked, detects meaningful changes, scores those changes across seven market-impact factors, and explains what actually matters — in plain English.
>
> Let’s see how it works.”

# SCENE 4 — THE CORE FEATURE: MEANINGFUL CHANGE & BASELINE TRACKING

**Duration: ~60–70 seconds**

### WHAT TO CLICK / SHOW

1. Return to the main **Watchlist**.
2. Show the **Attention Section**.
3. Focus on a **RED attention card**.
4. Slowly highlight:

   * Current price
   * Percentage change
   * Attention score
   * Relative performance vs NIFTY
   * Outperformed/Underperformed indicator
5. Show a **YELLOW** card.
6. Show a **GREEN** card.
7. Return to the RED card.
8. Highlight the **change since last seen** information.

### EXACT NARRATION

> “And this is where ShareBazaar becomes fundamentally different from a conventional watchlist.
>
> Instead of only showing today's percentage movement, ShareBazaar maintains a personal baseline for each user.
>
> When I last checked this stock, the system recorded its market price.
>
> That value becomes my last-seen baseline.
>
> When I return, the system compares the current market state against that snapshot.
>
> So the question isn't simply, ‘Is RELIANCE up today?’
>
> The question becomes, ‘What has changed since I last looked?’
>
> ShareBazaar then evaluates that change using a deterministic seven-factor Market Impact Score.
>
> The factors include price anomaly, volume anomaly, relative performance versus NIFTY, news impact, corporate events, catalyst proximity, and data confidence.
>
> The resulting score ranges from zero to one hundred.
>
> Scores of seventy or above become RED — high impact.
>
> Scores from forty to sixty-nine are YELLOW — medium impact.
>
> And below forty is GREEN — low impact.
>
> This means the interface isn't asking the investor to scan every number.
>
> It's prioritizing the changes that deserve attention.”

### IMPORTANT VISUAL MOMENT

Point directly at the RED card.

### SAY:

> “This is the important part: the red indicator isn't based on price movement alone. It represents a composite market-impact assessment.”

Then point to the relative-performance indicator.

### SAY:

> “The system also compares the stock against NIFTY, so an investor can distinguish a stock-specific move from a broader market move.”

### MARK AS SEEN DEMO

Click **Mark as Seen / Acknowledge**.

### SAY:

> “And once I've reviewed this movement, I don't want the same alert to keep appearing as new.
>
> That's why ShareBazaar has a Mark as Seen action.
>
> Clicking it updates my personal baseline to the current market price and resets the attention state.
>
> The next time I return, the system starts measuring from this new point.”

### EXACT NARRATION

> “Once ShareBazaar identifies something important, the next question is: why did it happen?
>
> That's where the AI explanation layer comes in.
>
> I'll click AI Insight, and ShareBazaar generates a concise, two-sentence explanation of the stock's movement using the available market signals.
>
> The goal isn't to generate a long AI report.
>
> It's to turn the underlying data into a quick, human-readable explanation that helps the investor understand the movement immediately.
>
> The system uses AI for this narrative layer, while also maintaining a fallback explanation so the experience remains useful even when the AI service isn't available.

>
> Here I can switch between one day, one week, one month, one year, and the full available history.

>
> That updates my baseline, so ShareBazaar can focus on what's new the next time I return.”

### EXACT NARRATION

> “Under the hood, ShareBazaar is built as a modular React and Node.js application backed by PostgreSQL.
>
> Market data follows a three-tier resilience model.
>
> The primary source is the Upstox API.
>
> If live data isn't available, ShareBazaar can fall back to the latest stored market snapshot.
>
> And if that isn't available, the system uses a real-time mock market-data generator, allowing the application to remain demonstrable instead of failing completely.
>
> The system also handles stale data automatically when the available data is older than twenty-four hours.
>
> User-specific baselines are persisted, while the frontend maintains a modular experience with preferences that persist between sessions.
>
> The result is a watchlist that doesn't just display the market.
>
> It remembers where the user left off, determines what changed, ranks what matters, and explains why.
>
> That's ShareBazaar — turning a traditional watchlist into real-time market intelligence.”
